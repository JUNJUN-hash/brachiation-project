# 枝渡りロボットの強化学習制御(2リンク・MuJoCo / 自作力学)

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://www.python.org/)
[![Gymnasium](https://img.shields.io/badge/Gymnasium-v0.29%2B-orange.svg)](https://gymnasium.farama.org/)
[![MuJoCo](https://img.shields.io/badge/MuJoCo-v3.0%2B-green.svg)](https://mujoco.org/)
[![Stable-Baselines3](https://img.shields.io/badge/Stable--Baselines3-PPO-green.svg)](https://stable-baselines3.readthedocs.io/)

テナガザルを模した劣駆動の枝渡りロボットを対象に、深層強化学習で運動を獲得し、シミュレーションで学習した制御を実機へ適用する際の課題を調べています。このリポジトリでは、研究のうち公開可能な範囲について、ラグランジュの運動方程式に基づく力学モデル、Gymnasium環境の設計、学習・評価の流れを紹介します。
1. 研究目的
高所の鉄塔や送電線の点検作業を自動化し、省人化と事故の削減につなげることを目的としています。
対象とする2リンク系では、第2関節（肘）のみを駆動します。駆動できる関節の運動を利用して、直接駆動できない関節も間接的に動かす必要があるため、制御則を手作業で設計することが難しい系です。そこで、深層強化学習による運動獲得に取り組み、パラメータ変動や外力を加えた条件でも方策を評価しています。
本研究では、主に次の3点に取り組んでいます。
- 劣駆動の枝渡り動作を、強化学習で獲得できるか
- パラメータ変動や外力がある条件で、学習した方策が機能するか
- シミュレーションで学習した制御を実機に適用する際、どのような差や課題が生じるか

3. 研究の段階と現在の状態
段階	内容	状態
A	2リンクの運動獲得(自作力学+MuJoCo)	達成済み
B	単リンクの、実機を模した環境(SAC)	実装中
C	単リンク実機での検証	一部達成・実装中
D	グリッパー付きモデルへの拡張	実装中(摩擦の同定段階)


A. 2リンクモデルでの運動獲得・評価（評価済み）
- 力学モデル: ラグランジュの運動方程式に基づいて2リンクの運動方程式を構築し、跳躍（空中飛行）の運動も実装しました。枝をつかむ際の衝突（撃力）と固定点の切り替えも、計算上で扱っています。
- 学習: Stable-Baselines3のPPOを使用し、報酬設計とハイパーパラメータの調整を行いました。
- 学習で獲得した動作:
  - 目標位置へのスイング(放物線を描く動き)
  - 垂れ下がった状態からの移動
  - 2リンクを伸ばし切った長さより遠い目標への跳躍
  - ばね・ダンパーで表した弾性のある枝を考慮した、上記の各動作
- 目標位置への移動タスク: MuJoCo上に、剛体枝の2リンクモデルがスイングを利用して目標位置へ移動し、到達時に静止することを目指す環境を構築しました。駆動するのは第2関節（肘）のみです。
  - 問題設定: 観測は関節角度の正弦・余弦と角速度からなる6次元、行動は第2関節に加えるトルクの1次元です。報酬の詳細は公開していません。
  - 実機パラメータの同定: 2リンクロボットで、トルク定数は電流と荷重の測定値の関係を最小二乗法で回帰して推定しました。粘性摩擦係数とクーロン摩擦係数は、ロボットを剛体振り子とみなし、モーションキャプチャ（OptiTrack、120 Hz）で計測した減衰運動から機械的エネルギーの損失量を求め、最小二乗法で推定しました。摩擦は第1関節側と第2関節側でそれぞれ5回測定し、平均値を用いました。同定値は公開していません。
  - パラメータ変動と外力: リンク長、質量、粘性摩擦係数、クーロン摩擦係数を変動させ、各リンクにはランダムな方向から外力を同時に加えました。外力は風そのものを直接再現したものではなく、高所での使用を想定した一様な力による近似です。
  - 初期状態の変動: 外力などによって初期状態がずれる状況を想定し、初期角度と初期角速度を変動させました。初期状態の評価では、学習時より広い範囲を使用しています。変動範囲の詳細は公開していません。
- 評価結果: グリッパー機構を持たない剛体枝の2リンクモデルで、学習した方策を100回試行し、97回で目標位置への移動に成功しました（成功率 97%）。成功条件は、手先と目標位置の誤差が0.01 m未満、かつ手先の終端速度が0.15 m/s未満であることです。これは、設定したシミュレーション条件下での移動タスクの結果であり、実機での成功率や把持を含むタスクの成功率ではありません。
  - 上記の100回試行とは別に、評価用の初期状態範囲から600点をサンプリングし、目標位置への到達可否を調べました。可動域の境界付近に到達が難しい初期状態が見られ、位置エネルギーの不足・過多や、境界付近での学習不足が原因候補と考えています。原因の特定は今後の課題です。
  - 弾性枝を考慮した動作は別条件での評価であり、上記の成功率には含まれません。
B. 単リンクの振り上げ学習（実装中）
- 目的: 実機での検証に向け、単リンクでエネルギーを蓄えて振り上げる動作を学習します。
- アルゴリズム: PPOでは学習が進みにくかったため、SACに変更して実装を進めています。SACの学習コードは、このリポジトリには含まれていません。
- 現在: 実機の挙動をシミュレーションに反映し、モデルの改善を進めています。
C. 単リンク実機での制御検証（一部検証済み・実装中）
- 検証系の違い: Aのパラメータ同定は、DYNAMIXELサーボモーターを用いた2リンクロボットで実施しました。一方、ここでの制御検証は、Teensy 4.1とSimpleFOCを用いた単リンク実機で進めています。対象とするロボット・制御系が異なるため、Aの同定結果とCの実機検証は区別して扱っています。
- 現状: 単リンク実機では、シミュレーションで想定した通りのトルク制御を実現できておらず、通信遅延も課題となっています。
- 原因分析: 課題を機械特性・センサ・計算処理・通信に分け、実機データを用いて検証しました。その結果、電流計測（ADC）処理の集中によって制御タイミングが乱れることを確認しました。
- 対策: ADC処理を分割し、2・3・4段階の構成を比較しました。比較した条件では、処理負荷と電流値の更新頻度・応答性のバランスを考慮し、3段階の構成を選定しました。
- 現在: シミュレーションに近いトルクを実現するため、電流フィードバック制御の実装を進めています。
D. グリッパー付きモデルへの拡張（実装中）
- 目的: 移動後の把持まで扱うため、グリッパー機構を備えたモデルへ拡張します。
- 現在: グリッパー付きモデルの粘性摩擦係数とクーロン摩擦係数を同定している段階です。学習環境は実装中であり、学習結果はまだ得られていません。
- 評価方針: 移動と把持を分けて評価し、把持を含むタスクの結果は、2リンクの移動タスクで得た成功率とは別に扱います。
4. 設計
力学モデルと強化学習環境（Gymnasium）を分けて実装しています。これにより、力学モデルや枝の条件を変更した際も、環境・学習・評価の構成を整理して比較できる設計にしています。
構成	役割
力学モデル	ラグランジュの運動方程式に基づく自作モデル、MuJoCo
Gymnasium環境	観測・行動・報酬・外力、フェーズ遷移、終了判定
学習	Stable-Baselines3(PPO)
評価・解析	動作確認と、角度・角速度・トルクなどの時系列の解析


使用技術: Python 3.10+、Gymnasium、Stable-Baselines3、MuJoCo、NumPy、SciPy、Matplotlib

## 5. 使い方

```bash
pip install -r requirements.txt

# 学習(公開版では、報酬の係数とハイパーパラメータを簡略化しています)
python pendulum_leap_train.py

# 動作確認(学習で得たモデルを使います)
python enjoy.py
```

公開版の報酬とハイパーパラメータは、研究で用いた値ではありません。そのため、研究での成功率は再現されません。

## 7. 公開範囲について

研究を継続中のため、次の内容は公開していません。

- 報酬の係数、ハイパーパラメータ
- 実測して同定した値
- 学習済みモデル、実験データ、実験の動画
- 実機側の制御コード

公開しているのは、問題設定、力学モデルの構成、環境の設計、アルゴリズムの選定、学習と評価の流れです。このリポジトリの目的は、研究の結果をそのまま再現できる形で出すことではなく、どのような問題設定と環境設計で、どのように課題へ取り組んでいるかを示すことです。
